# WH8 信号公式瘦身

麦语言(WH8平台)批量信号定义文件常常是这样的：`AJ_00018:=A && B && C && ...;`
成百上千行，`&&` 连接的条件项之间大量重复组合。这个工具自动把重复片段提成
公共定义，原信号行改成引用这些定义，同时保证逻辑与原文件完全等价。

Claude Code 项目里使用时，直接把这个仓库放在 `.claude/skills/wh8-factor/`，
用户说"瘦身/精简这个麦语言文件"时会自动触发，具体规则见 [SKILL.md](SKILL.md)。

## 用法

```bash
python3 scripts/factor_wh8.py <输入.txt>
```

默认输出 `<输入文件名>_精简.txt`，同目录，原文件不动。脚本内置校验：把生成的
每个别名递归展开还原，逐条按原顺序与原文件比对条件项；只要有一条不一致就
报错退出、不写出文件——终端打印 `校验通过: N/N ...` 才代表结果可信。

## 参数

| 参数 | 作用 | 默认 |
|---|---|---|
| `-o <路径>` | 指定输出文件路径 | `<输入>_精简.txt` |
| `-p <字母>` | 别名前缀字母，生成 `AJ_<字母>1, AJ_<字母>2...` | `A` |
| `--min-count N` | 片段至少重复几次才提取 | `4` |
| `--min-save N` | 提取净节省字符数门槛，越小提取越激进 | `80` |
| `--reuse-from <已精简文件.txt>` | 本次提取出的定义，展开到叶子条件项后如果和该文件里某个已有定义完全相同，就不重新定义，直接复用它的别名 | 不传则不复用 |

多个文件合并进同一个指标时，给每个文件用不同前缀字母（`-p A`、`-p B`...）避免
别名冲突；多个文件各自分开瘦身但存在相同重复定义时，用 `--reuse-from` 让后面
的文件复用前面文件已有的定义（此时 WH8 里贴的顺序必须是被复用的文件在前）。
详见 [SKILL.md](SKILL.md)。
